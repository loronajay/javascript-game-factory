# Player character assets

- `base-character.glb`: Quaternius Universal Base Characters Standard,
  `Superhero_Male_FullBody`, converted to an embedded GLB with textures capped at 1024 px.
- `locomotion.glb`: Quaternius Universal Animation Library Standard, in-place edition.

Both source packs are CC0 1.0. Runtime copies were retrieved from the audited conversions in
https://github.com/Seyamalam/blood-league-kickoff/tree/main/public/assets/vendor/quaternius.
