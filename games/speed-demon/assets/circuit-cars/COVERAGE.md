Verified coverage: **24 / 24 garage models**, each with eight headings and a transparent 512×64 runtime atlas.

The race renderer normalizes visible alpha area and anchors each heading by its body centre; the inspection viewer uses that same sizing. Garage stripe position, width, and positive/negative curve settings are preserved by the production livery bake.

Tsunami has replacement art with distinct front/rear views. Chrono cardinal headings were corrected after visual inspection. All runtime sheets pass transparent-border and background-key checks. The full npm test suite passes, including every model at all eight headings with saved positive and negative stripe curves.
